# Sistema de Pedidos de Comida Local - Cusco

Proyecto del Laboratorio 1: Introducción al entorno de desarrollo y Git.
Curso: Ingeniería de Software.

## Descripción

Una startup en Cusco quiere desarrollar un sistema web para gestionar pedidos de comida local. Este repositorio es la base del proyecto y se usa para practicar control de versiones con Git y GitHub.

## Herramientas

- Visual Studio Code
- Git
- GitHub

## Pasos realizados

1. Instalar Git y configurar el usuario:

```bash
git config --global user.name "Tu Nombre"
git config --global user.email "correo@ejemplo.com"
```

2. Crear el repositorio local:

```bash
git init
git branch -M main
```

3. Hacer el primer commit:

```bash
git add README.md
git commit -m "Primer commit"
```

4. Conectar con GitHub y subir:

```bash
git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
git push -u origin main
```

## Reflexión

**¿Por qué Git es crítico en proyectos colaborativos?**
Permite que varias personas trabajen en el mismo código sin pisarse y guarda un historial de los cambios.

**¿Qué problemas evita?**
Evita perder código, sobrescribir el trabajo de otros y tener versiones desordenadas.
